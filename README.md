# xh-hub

Marketplace index cho các plugin Claude của Ngô Xuân Hưng. Repo này chỉ chứa
`.claude-plugin/marketplace.json` — không chứa code plugin. Code plugin nằm ở
các repo riêng:

- `xh-tuvan` → https://github.com/xuanhungsiwrr-web/XH-rda
- `ai-governance` → https://github.com/xuanhungsiwrr-web/ai-space-governance

## Cài trong Claude Desktop

Settings > Plugins > Marketplaces > Add marketplace, dán URL repo này
(`xuanhungsiwrr-web/xh-hub`), sau đó cài các plugin bên trên từ marketplace
đó.
